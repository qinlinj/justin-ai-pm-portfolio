INDUSTRY PERSPECTIVE & CAREER DIRECTION

When agents can act,
what must the product own?

My view: model capability determines what we can attempt; workflow design determines whether we can deliver reliably. Technical AI PM work connects user goals, system constraints, and release criteria.

01 / SCOPE

More autonomy is not always better.

Prefer fixed workflows where rules are clear and mistakes are costly. Use agents for dynamic decisions within explicit tool permissions and budgets.

02 / EVALUATION & RELEASE

Let task outcomes guide the next change.

Track completion, human handoff, unauthorized actions, latency, and cost. Locate the failing stage before changing retrieval, prompts, or model training.

03 / LONG-TERM VALUE

Memory and knowledge need governance.

A persistent agent needs to know what remains valid, who can change it, and when to forget it. Correction and provenance make knowledge worth reusing.

Seeking technical AI PM and agent product / systems design roles, working closely with engineers across requirements, architecture, evaluation, and delivery.
