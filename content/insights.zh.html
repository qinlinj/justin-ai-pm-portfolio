行业判断与职业方向

让 Agent 做事，
也要明确何时停下。

客服接入和旅行规划指向同一个产品问题：哪些决定交给系统，哪些必须由人来做？

01 / 自主范围

按风险决定放权范围

资料检索可以在授权范围内自动完成。退款会改变业务状态，action gate 必须检查权限、执行条件和操作结果。模型有把握，不等于有权执行。不可逆操作由指定负责人批准。

02 / EVALS 与协作

多 Agent 要算清协作成本

交通、住宿可以并行研究，最终行程却必须一致。先用单 Agent 建立基线，再拆出独立任务。任务级 evals 同时检查约束、失败恢复、成本和耗时。权限违规单独检查，不能被平均得分掩盖。

03 / MEMORY

记住什么，也要能撤回

行程状态、个人偏好和公司规则，保留期限各不相同。偏好经用户同意后保存，依据保留来源与版本。信息纠错、删除或权限变化后，旧上下文必须失效。用跨会话 evals 检查这些变化。
